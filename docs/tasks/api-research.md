#### GET /uploads/{id}

**Источник:** `upload_worker.py:60–61` (по BookFusion ID)  
**Источник:** `upload_worker.py:70–71` (по SHA-256 дайджесту файла)

**Назначение:** Проверить, загружена ли книга. Используется в двух сценариях:
1. Если у книги есть идентификатор `bookfusion` — передаётся числовой BookFusion ID.
2. Если нет ни `bookfusion`, ни `isbn` — передаётся SHA-256 дайджест файла (hex-строка).

**Path-параметр:**

| Параметр   | Тип      | Значение                                         |
|------------|----------|--------------------------------------------------|
| `{id}`     | `string` | BookFusion ID (целое число) или SHA-256 дайджест |

**Ответ (HTTP 200) — одиночный объект:**

| Поле                      | Тип       | Описание                                      |
|---------------------------|-----------|-----------------------------------------------|
| `id`                      | `integer` | BookFusion внутренний ID книги                |
| `calibre_metadata_digest` | `string`  | SHA-256 дайджест метаданных предыдущей загрузки |

**Ошибки:**

| Код   | Обработка                                    |
|-------|----------------------------------------------|
| 401   | Показывает `'Invalid API key.'`              |
| 404   | Книга не найдена → начать загрузку           |
| 500   | Логирует ответ, не прерывает синхронизацию   |
| иной  | Логирует ответ, не прерывает синхронизацию   |

#### GET /uploads

**Источник:** `upload_worker.py:63–64`

**Назначение:** Поиск загрузки по ISBN. Используется если у книги есть идентификатор `isbn`, но нет `bookfusion`.

**Query-параметры:**

| Параметр | Тип      | Обязательный | Описание  |
|----------|----------|:---:|----|
| `isbn`   | `string` | да  | ISBN книги |

**Ответ (HTTP 200) — массив объектов:**

```json
[
  {
    "id": 123,
    "calibre_metadata_digest": "abc123..."
  }
]
```

Если книга не найдена — пустой массив `[]`. Плагин берёт только первый элемент `results[0]`.

| Поле                      | Тип       | Описание                                        |
|---------------------------|-----------|-------------------------------------------------|
| `id`                      | `integer` | BookFusion внутренний ID книги                  |
| `calibre_metadata_digest` | `string`  | SHA-256 дайджест метаданных предыдущей загрузки |

**Ошибки:** аналогично `GET /uploads/{id}`.

#### POST /uploads/init

**Источник:** `upload_worker.py:139–144`

**Назначение:** Инициализация загрузки новой книги — получить presigned URL для S3.

**Тело запроса:** `multipart/form-data`

| Поле       | Тип      | Описание                               |
|------------|----------|----------------------------------------|
| `filename` | `string` | Имя файла (basename), например `book.epub` |
| `digest`   | `string` | SHA-256 дайджест содержимого файла (hex) |

**Ответ (HTTP 200):**

| Поле     | Тип                       | Описание                                                |
|----------|---------------------------|---------------------------------------------------------|
| `url`    | `string`                  | URL внешнего хранилища (S3) для загрузки файла          |
| `params` | `object<string, string>`  | Поля для включения в multipart-запрос к `url` (ключи не зафиксированы # UNVERIFIED) |

**Ошибки:**

| Код | Обработка                                     |
|-----|-----------------------------------------------|
| 401 | Показывает `'Invalid API key.'`               |
| 422 | Читает `{"error": "..."}`, логирует           |

#### POST {upload_url} — внешнее хранилище (S3)

**Источник:** `upload_worker.py:164–178`

**Назначение:** Загрузить бинарный файл книги напрямую в S3 (или аналогичный сервис). URL и параметры получены из ответа `POST /uploads/init`.

**Тело запроса:** `multipart/form-data`

| Поле        | Тип      | Описание                                                            |
|-------------|----------|---------------------------------------------------------------------|
| `{key}`     | `string` | Каждый ключ из `params` объекта ответа `/uploads/init`             |
| `file`      | `binary` | Содержимое файла книги                                              |

Примечание: порядок полей — сначала все `params`, последним — `file`.

**Ответ (HTTP 200):** тело не используется плагином.

**Ошибки:** при сетевых ошибках (`ConnectionRefusedError`, `RemoteHostClosedError`, `HostNotFoundError`, `TimeoutError`, `TemporaryNetworkFailureError`) — до 2 повторных попыток.

#### POST /uploads/finalize

**Источник:** `upload_worker.py:199–213`

**Назначение:** Завершить загрузку — привязать загруженный файл к метаданным книги.

**Тело запроса:** `multipart/form-data`

| Поле                              | Тип      | Обязательный | Описание                                                                |
|-----------------------------------|----------|:---:|-------------------------------------------------------------------------|
| `key`                             | `string` | да  | Значение `params['key']` из ответа `/uploads/init`                      |
| `digest`                          | `string` | да  | SHA-256 дайджест содержимого файла (hex)                                |
| `metadata[calibre_metadata_digest]` | `string` | да  | SHA-256 дайджест метаданных (см. алгоритм ниже)                         |
| `metadata[title]`                 | `string` | да  | Название книги                                                          |
| `metadata[summary]`               | `string` | нет | Аннотация (`comments` в Calibre)                                        |
| `metadata[language]`              | `string` | нет | Язык (первый из списка языков)                                          |
| `metadata[isbn]`                  | `string` | нет | ISBN                                                                    |
| `metadata[issued_on]`             | `string` | нет | Дата публикации, ISO 8601 (`YYYY-MM-DD`). Не передаётся если `0101-01-01` |
| `metadata[series][][title]`       | `string` | нет | Название серии (повторяется для каждой серии)                           |
| `metadata[series][][index]`       | `string` | нет | Номер в серии (повторяется; не передаётся если `None`)                  |
| `metadata[author_list][]`         | `string` | нет | Автор (повторяется для каждого автора)                                  |
| `metadata[tag_list][]`            | `string` | нет | Тег (повторяется для каждого тега)                                      |
| `metadata[bookshelves][]`         | `string` | нет | Полка (первый элемент — пустая строка-сентинель, затем значения)        |
| `metadata[cover]`                 | `binary` | нет | Обложка книги (файл)                                                    |

**Ответ (HTTP 200):**

| Поле | Тип       | Описание                    |
|------|-----------|-----------------------------|
| `id` | `integer` | BookFusion внутренний ID книги |

**Ошибки:**

| Код | Обработка                                        |
|-----|--------------------------------------------------|
| 422 | Читает `{"error": "..."}`, показывает пользователю |
| 401 | Показывает `'Invalid API key.'`                  |

**Ошибки:** аналогично `POST /uploads/finalize`.

### Алгоритм `calibre_metadata_digest`

**Источник:** `upload_worker.py:275–322`

SHA-256 от конкатенации следующих полей в UTF-8 (поля с `None` пропускаются):

1. `title` (обязательное)
2. `summary` (`comments`)
3. `language` (первый элемент)
4. `isbn`
5. `issued_on` (ISO-дата, пропускается если `'0101-01-01'`)
6. Для каждой серии: `series.title`, `series.index` (если не `None`)
7. Для каждого автора: `author`
8. Для каждого тега: `tag`
9. Для каждой полки: `bookshelf`
10. Если есть обложка: `bytes(filesize)` + `\0` + содержимое файла блоками по 65536 байт

## Obsidian API

### Аутентификация

**Механизм:** Token-based. Пользователь нажимает "Connect" → открывается браузер с `/obsidian-api/connect` → BookFusion редиректит обратно в Obsidian через deep link `obsidian://bookfusion-connect?token={token}`.

**Источник:** `settings_tab.ts:110–113`, `plugin.ts:72–76`

### Эндпоинты Obsidian API

#### GET /obsidian-api/connect

**Источник:** `settings_tab.ts:110–119`

**Назначение:** Страница авторизации в браузере. После входа BookFusion открывает Obsidian через protocol handler.

#### POST /obsidian-api/sync

**Источник:** `bookfusion_api.ts:5–6`, `bookfusion_api.ts:95–105`

**Назначение:** Получить страницы книг и/или индексных файлов для синхронизации. Поддерживает пагинацию через курсор.

**Заголовки:**

| Заголовок        | Значение                  | Описание                        |
|------------------|---------------------------|---------------------------------|
| `Content-Type`   | `application/json`        | Тип тела запроса                |
| `X-Token`        | `{token}`                 | Токен аутентификации            |
| `API-Version`    | `1`                       | Версия API (строка `"1"`)       |

**Тело запроса (JSON):**

| Поле     | Тип              | Описание                                                                 |
|----------|------------------|--------------------------------------------------------------------------|
| `cursor` | `string \| null` | Курсор пагинации. `null` — первый запрос; строка — продолжение пагинации |

**Ответ (HTTP 200, JSON):**

| Поле               | Тип              | Описание                                                                        |
|--------------------|------------------|---------------------------------------------------------------------------------|
| `pages`            | `Page[]`         | Массив страниц для обработки (см. структуры ниже)                               |
| `cursor`           | `string \| null` | Курсор следующей страницы пагинации. `null` — пагинация завершена               |
| `next_sync_cursor` | `string \| null` | Курсор для сохранения — передать в следующей *сессии* синхронизации             |

**Пагинация:** запросы повторяются с `cursor` из предыдущего ответа пока `cursor != null`.

**Ошибки:**

| Код       | Тело ответа               | Обработка                                  |
|-----------|---------------------------|--------------------------------------------|
| не 2xx    | `{"message": "..."}`      | Бросает `APIError` с `message`             |

## Открытые вопросы

1. **Структура `params` в ответе `/uploads/init`** — плагин итерирует все ключи, ни один не зафиксирован в коде, кроме `key` (который используется в `/uploads/finalize`). Остальные ключи неизвестны. `# UNVERIFIED`
2. **Тип `id` в `/uploads/{id}`** — используется как путь-параметр, в коде приходит как `result['id']` (Python dict — скорее всего `int`), затем передаётся в `str(bookfusion_id)`. Точный тип в JSON-ответе — `int` или `string` — не верифицирован. `# UNVERIFIED`
3. **Ответ `PUT /uploads/{id}`** — тело ответа не парсится плагином, структура неизвестна. `# UNVERIFIED`
4. **Поле `bookshelves` — пустая строка первым элементом** — плагин всегда добавляет `metadata[bookshelves][] = ""` перед реальными значениями. Это стандартный Rails-паттерн сериализации массивов: пустой элемент гарантирует что сервер получит массив (а не отсутствие поля) даже если у книги нет полок, что позволяет серверу **заменить** список полок на пустой. Без этой строки Rails проигнорирует `bookshelves[]` если массив пустой. `# UNVERIFIED`
5. **Поля `cursor` и `next_sync_cursor`** — различие в семантике: `cursor` — для пагинации внутри одного вызова синхронизации, `next_sync_cursor` — для следующего запуска. Точная механика сервера не верифицирована. `# UNVERIFIED`
6. **`API_DEVICE` (env-переменная из CLAUDE.md)** — не найден ни в одном API-вызове обоих плагинов. Calibre использует `api_key` (Basic Auth), Obsidian — `token` (X-Token). Возможно `API_DEVICE` относится к другому плагину или зарезервирован для будущей реализации. При написании тестов (Этап 3) это поле можно пропустить или оставить как заглушку.
